# Agent instructions

## Planning and continuity

- The GitHub issue owns execution. Fill `.github/pull_request_template.md` for every PR.
- Implemented, merged, verified and delivered are four different claims. Use `Closes #N` (or a Development-sidebar link) only when the merge finishes the issue; otherwise use `Refs #N`, keep the issue open with the `open-item` label, and say what is left and how to check it.
- Planning never drifts: every issue and PR carries a `Planning:` line, and scope changes update their planning record in the same PR (see `docs/planning.md`).
- Never cite a path outside this repository, such as a local report, in a repo file, issue or PR; copy the substance.
